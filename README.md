# 🧫 Bacterial Evolution - Plague Inc Style Game

Браузерная игра в стиле Plague Inc, где ты управляешь эволюцией бактерии и заражаешь человечество!

![Game Screenshot](screenshot.png) *Добавь скриншот игры*

## 🎮 Игровой процесс

- 🧬 **Собирай ДНК** - очки эволюции начисляются за зараженных людей
- 🔬 **Развивай болезнь** - три ветки эволюции: передача, симптомы и способности
- 🌍 **Захватывай регионы** - 5 регионов с разным населением
- 💀 **Уничтожай человечество** - или проиграешь, если болезнь исчезнет

## 🚀 Как играть

1. Открой игру по ссылке: [noz1ks.github.io/NEW](https://noz1ks.github.io/NEW)
2. Начинай с Китая (1000 зараженных)
3. Покупай улучшения за ДНК
4. Следи за распространением болезни
5. Победи - зарази всех!
